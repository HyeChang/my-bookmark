# 모바일 작업 패널 설계

작성일: 2026-04-15

## 목표

- 모바일 화면에서 사이드바 작업 영역의 세로 길이를 줄인다.
- `북마크 저장`, `폴더 관리`, `태그 관리`를 접이식 패널로 바꿔 작은 화면에서도 빠르게 전환할 수 있게 한다.
- 데스크톱 구조와 기존 폼 동작은 유지한다.

## 범위

- 모바일 전용 패널 토글 UI
- 모바일 기본 열림 상태 정의
- 데스크톱과 모바일에서 같은 폼 로직 재사용
- 접근성 속성(`aria-expanded`, `aria-controls`) 정리

## 제외 범위

- 각 폼 필드나 저장 로직 변경
- 탭 구조 전환
- 드래그, 정렬, 검색 로직 변경
- 데스크톱 사이드바 레이아웃 변경

## 설계

### 1. 패널 구조

- 사이드바의 세 작업 영역은 그대로 유지한다.
- 모바일에서는 각 패널 제목 행이 토글 버튼 역할을 한다.
- 패널 본문은 열린 패널만 렌더링한다.

### 2. 기본 상태

- 모바일 최초 진입 시 `북마크 저장`만 열린다.
- `폴더 관리`, `태그 관리`는 닫힌 상태로 시작한다.
- 데스크톱에서는 세 패널이 모두 열린 상태를 유지한다.

### 3. 토글 규칙

- 모바일에서는 한 번에 하나의 패널만 연다.
- 이미 열려 있는 패널 제목을 눌러도 닫지 않고, 해당 패널을 유지한다.
- 다른 패널 제목을 누르면 기존 열린 패널은 닫히고 새 패널이 열린다.

### 4. 접근성

- 각 제목 버튼은 `aria-expanded`로 상태를 노출한다.
- 각 버튼은 대응되는 본문 컨테이너와 `aria-controls`로 연결한다.
- 본문 컨테이너는 기존 `region` 라벨(`bookmark-form`, `folder-manager`, `tag-manager`)을 유지한다.

### 5. 스타일

- 모바일에서는 패널 제목 버튼이 카드 상단 전체 폭을 차지한다.
- 열린 패널은 제목 아래에 본문이 이어지고, 닫힌 패널은 제목 행만 남긴다.
- 데스크톱에서는 제목 버튼을 별도 토글처럼 보이게 하지 않고 기존 카드 헤더처럼 보이게 유지한다.

## 테스트 기준

- 모바일 폭에서 초기 렌더 시 `북마크 저장` 패널만 열린다.
- 모바일에서 `폴더 관리` 버튼을 누르면 폴더 폼이 보이고, 북마크 저장 폼은 숨겨진다.
- 데스크톱 폭에서는 세 패널이 모두 보인다.
