# 폴더/태그 수정·삭제 설계

## 목표

사용자가 등록한 폴더와 태그를 대시보드에서 바로 수정하거나 삭제할 수 있게 하고, 삭제 시 북마크 상태도 함께 정리해 dangling 참조를 남기지 않는다.

## 범위

- API에 폴더 삭제와 태그 수정/삭제 엔드포인트 추가
- 웹 대시보드의 폴더/태그 관리 섹션에 수정 모드와 삭제 버튼 추가
- 폴더 삭제 시 해당 폴더를 사용하던 북마크의 `folder_id`를 `null`로 정리
- 태그 삭제 시 해당 태그와 연결된 `bookmark_tags`를 함께 삭제
- 수정/삭제 후 북마크 목록, 상세 패널, 편집 폼 상태 동기화

## 접근 방식

- 폴더는 기존 `PATCH` 흐름을 재사용하고 `DELETE`만 추가한다.
- 태그는 저장소와 라우트에 `PATCH`, `DELETE`를 추가한다.
- 웹은 생성 폼을 수정 폼으로 재사용하고, 선택한 항목을 편집 중일 때 버튼 문구와 제출 동작을 바꾼다.
- 삭제 후에는 로컬 상태에서 폴더/태그를 제거하고, 북마크와 선택 상태에 남은 참조도 즉시 정리한다.

## 비범위

- 폴더 계층 이동 UI
- 태그 병합
- 다중 선택 삭제

## 검증 포인트

- 폴더 이름/색상/아이콘을 수정할 수 있다.
- 태그 이름/색상을 수정할 수 있다.
- 폴더 삭제 후 북마크 폴더 선택값이 비워진다.
- 태그 삭제 후 북마크 태그 선택값과 상세 표시가 정리된다.
