# 북마크 삭제 설계

## 목표

사용자가 저장한 북마크를 목록과 상세 패널에서 삭제할 수 있도록 하고, 연관된 태그 연결, 자산 메타데이터, 열람 활동 기록, 업로드된 이미지 객체도 함께 정리한다.

## 범위

- API에 `DELETE /api/bookmarks/:bookmarkId` 추가
- 삭제 시 다음 데이터 정리
  - `bookmark_tags`
  - `bookmark_assets`
  - `bookmark_activity`
  - `bookmark_extraction_logs`
  - `bookmarks`
- 업로드된 R2 객체 삭제
- 목록과 상세 패널에 삭제 버튼 추가
- 삭제 전 브라우저 `confirm` 확인 추가
- 삭제 후 목록, 상세 패널, 추천 상태에서 북마크 제거

## 접근 방식

- 삭제 대상 북마크와 연결된 자산 목록을 먼저 조회한다.
- R2 객체 키를 확보한 뒤 북마크 메타데이터를 삭제하고, 각 객체도 저장소에서 삭제한다.
- 웹에서는 공용 `deleteBookmark()` 클라이언트를 추가하고, 상태에서 북마크와 관련 자산, 추천 항목, 상세 패널 선택 상태를 함께 비운다.

## 비범위

- 폴더/태그 삭제
- 휴지통/복구 기능
- 다중 선택 삭제

## 검증 포인트

- 인증된 사용자는 자기 북마크를 삭제할 수 있다.
- 삭제 후 목록에서 항목이 사라진다.
- 상세 패널에서 삭제 시 패널이 닫힌다.
- 연결된 이미지 콘텐츠 요청이 더 이상 성공하지 않는다.
