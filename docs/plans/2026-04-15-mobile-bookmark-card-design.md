# 모바일 북마크 카드 최적화 설계

## 목표

작은 화면에서 북마크 목록 카드를 더 빠르게 스캔하고 더 쉽게 조작할 수 있게 만든다. 카드 높이를 줄이되, 상세 정보는 계속 상세 패널에서 확인할 수 있게 유지한다.

## 접근

### 1. 카드 정보 밀도

- 모바일에서는 카드 내부 순서를 `제목 -> URL -> 핵심 배지 -> 요약 -> 액션`으로 압축한다.
- 핵심 배지는 `폴더`, `즐겨찾기`, `요약 상태`, `태그 수`, `이미지 수`까지만 노출한다.
- 개별 태그 이름 목록은 모바일 카드에서 숨기고 상세 패널에서 확인하게 한다.

### 2. 색상/이미지 축약

- 모바일 카드에서는 `북마크 색상`, `URL 색상`을 각각 긴 텍스트로 보여주지 않고, 색상 설정이 있으면 `색상 설정됨` 하나로 축약한다.
- 업로드 이미지는 목록 카드에서 실제 썸네일 그리드를 렌더링하지 않고, `이미지 n장` 배지로만 유지한다.

### 3. 액션 흐름

- 모바일 카드 액션은 `열기`, `상세 보기`, `수정`, `삭제` 순으로 재배치한다.
- 액션은 모바일에서 전체 폭 세로 스택으로 정리해 터치 정확도를 높인다.

### 4. 범위

- 데스크톱 카드 구조는 유지한다.
- 상세 패널과 추천 섹션은 이번 슬라이스에서 건드리지 않는다.
- 검색, 추천, API 로직은 변경하지 않는다.

## 테스트

- 모바일 뷰포트에서 카드가 개별 태그 이름과 이미지 썸네일 없이 압축형으로 보이는지 확인
- 모바일 카드 액션 순서가 `열기 -> 상세 보기 -> 수정 -> 삭제`인지 확인
- 데스크톱 테스트는 기존대로 유지
