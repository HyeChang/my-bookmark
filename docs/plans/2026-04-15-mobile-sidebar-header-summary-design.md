# 모바일 작업 패널 헤더 요약 설계

작성일: 2026-04-15

## 목표

- 모바일에서 접힌 작업 패널도 현재 상태를 한눈에 읽을 수 있게 만든다.
- 패널을 열지 않아도 각 영역의 역할과 현재 상태를 빠르게 파악하게 한다.
- 기존 토글 동작과 폼 로직은 유지한다.

## 접근 방식

### 옵션 1. 상태 요약만 추가

- 각 패널 제목 줄 아래에 짧은 요약 문구만 추가한다.
- 구현이 가장 안전하다.
- 이번 슬라이스 추천안이다.

### 옵션 2. 상태 요약 + 배지 추가

- 요약 문구와 별도로 작은 배지를 여러 개 붙인다.
- 정보량은 늘어나지만 모바일 헤더가 쉽게 복잡해진다.

### 옵션 3. 상태 요약 + 탭형 전환

- 헤더 요약과 함께 패널 전환 구조도 바꾼다.
- 효과는 크지만 범위가 커져 이번 슬라이스에는 과하다.

## 추천안

- 옵션 1로 진행한다.
- 모바일 작업 패널은 지금 구조를 유지하고, 헤더 정보만 강화한다.

## 헤더 요약 규칙

### 북마크 저장 패널

- 기본 상태: `새 북마크`
- 북마크 수정 중: `수정 중`
- 새로 입력 중이고 수정 상태가 아닐 때: `작성 중`

입력 중 판단 기준:

- `url`, `userTitle`, `userContent`, `userSummary`, `bookmarkColor`, `urlColor` 중 하나라도 값이 있음
- 선택된 태그가 하나 이상 있음
- 이미지 파일이 대기 중임
- 즐겨찾기가 체크됨

### 폴더 관리 패널

- 기본 상태: `폴더 N개`
- 폴더 수정 중: `수정 중 · 폴더 N개`

### 태그 관리 패널

- 기본 상태: `태그 N개`
- 태그 수정 중: `수정 중 · 태그 N개`

## 시각 구조

- 제목은 첫 줄에서 가장 크게 유지한다.
- 요약 문구는 두 번째 줄 보조 텍스트로 보여준다.
- 오른쪽에는 현재 확장 상태를 작은 배지와 기호로 유지한다.
- 모바일에서만 이 요약 구조를 적용하고, 데스크톱 헤더는 기존 카드 제목을 유지한다.

## 제외 범위

- 패널 전환 방식을 탭형으로 변경하지 않음
- 패널 내부 폼 구조 변경 없음
- 저장/수정 로직 변경 없음

## 테스트 기준

- 모바일에서 기본 렌더 시 북마크 패널 헤더에 `새 북마크`가 보인다.
- 모바일에서 폴더/태그 패널 헤더에 각각 `폴더 N개`, `태그 N개`가 보인다.
- 수정 시작 상태에서는 해당 패널 헤더가 `수정 중`을 포함해 바뀐다.
