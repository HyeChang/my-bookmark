# 대시보드 UI 정리 설계

## 목표

기존 기능을 바꾸지 않고, 인증 후 대시보드의 정보 구조를 더 명확하게 만든다.

- 검색/필터 영역을 상단 제어 패널로 분리
- 북마크 저장/폴더/태그 관리를 좌측 작업 패널로 정리
- 추천/상세/목록을 메인 콘텐츠 영역으로 재배치
- 모바일과 데스크톱에서 모두 읽기 쉬운 카드형 레이아웃 적용

## 범위

이번 슬라이스는 UI 정리만 포함한다.

- CSS 파일 추가
- 주요 섹션에 구조용 래퍼와 클래스 추가
- 검색 필터 칩, 폴더 트리, 추천 목록, 북마크 목록의 카드형 정리

이번 슬라이스에서 제외한다.

- 기능 로직 변경
- 새 API 추가
- 드래그 동작 변경
- 디자인 시스템 분리

## 레이아웃 방향

### 1. 상단 헤더

- 앱 제목과 설명을 `hero` 형태로 배치
- 로그인한 사용자의 이메일과 로그아웃 버튼을 우측 상태 영역으로 분리

### 2. 본문 2열 구조

- 좌측: `작업 패널`
  - 북마크 저장/수정
  - 폴더 관리
  - 태그 관리
- 우측: `콘텐츠 패널`
  - 검색 패널
  - 추천 링크
  - 북마크 상세
  - 저장된 북마크

모바일에서는 위 순서를 유지한 단일 열로 접는다.

### 3. 카드형 시각 구획

- 각 주요 영역은 공통 카드 스타일을 사용한다.
- 제목, 보조 설명, 액션 버튼의 간격을 일정하게 맞춘다.
- 현재 기능 텍스트는 유지하되, 정보 그룹만 나눈다.

## 검색 UI 정리

- `기본 검색`과 `고급 필터`를 별도 행으로 구분
- 활성 필터 칩은 별도 카드 블록으로 표시
- 검색 폼 전체를 `search-panel` region으로 감싼다.

## 폴더/태그 UI 정리

- 폴더/태그 관리 섹션을 공통 작업 패널 스타일로 맞춘다.
- 폴더 트리 행은 이름, 보조 정보, 액션 그룹을 분리한다.
- 드래그/이동 버튼은 액션 그룹 안에서 정렬한다.

## 북마크 목록 UI 정리

- 추천 목록은 3열 카드 묶음으로 배치하고, 모바일에서는 1열로 접는다.
- 북마크 목록 각 항목은 제목, 메타, 요약, 액션으로 나눈다.
- 상세 패널도 같은 카드 계열 스타일로 맞춘다.

## 테스트 전략

### Web

- 인증 후 `dashboard-sidebar`, `dashboard-main`, `search-panel` 구조가 보이는지 확인
- 사이드바 안에 `bookmark-form`, `folder-manager`, `tag-manager`가 들어가는지 확인
- 검색 패널 안에 `기본 검색`, `고급 필터`와 액션 버튼이 유지되는지 확인

API 변경은 없으므로 기존 API 테스트만 유지한다.
