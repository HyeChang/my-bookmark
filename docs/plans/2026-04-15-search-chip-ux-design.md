# 검색 칩 UX 정리 설계

## 목표

검색 패널의 활성 필터 칩을 더 빠르게 읽고, 더 쉽게 해제할 수 있게 만든다. 기능 로직은 유지하고, 시각적 계층과 텍스트 구조를 정리하는 데 집중한다.

## 접근

### 1. 칩 구조

- 각 칩은 `그룹 라벨 + 값 + 제거 기호` 구조로 표시한다.
- 그룹 라벨은 `검색어`, `기간`, `분류`, `상태`, `정렬` 중 하나다.
- 태그는 묶음 텍스트가 아니라 개별 칩을 유지하되, `분류: 태그 research`처럼 그룹을 읽을 수 있게 한다.

### 2. 요약 영역

- 요약 상단은 계속 `선택된 필터 n개`를 유지한다.
- 칩 목록 위에 별도 긴 설명 문장은 두지 않는다.
- 칩 리스트는 밀도 높은 배지형이 아니라, 각 칩이 하나의 독립된 조작 단위처럼 보이게 한다.

### 3. 시각 스타일

- 칩은 기본 버튼보다 조금 더 낮은 시각 무게를 가지되, hover 시 제거 동작이 명확히 보여야 한다.
- 그룹 라벨은 작은 보조 라벨, 값은 본문 텍스트, 제거 기호는 별도 작은 슬롯처럼 처리한다.
- 모바일에서는 칩이 폭을 과도하게 차지하지 않도록 줄바꿈과 최소 높이를 보장한다.

### 4. 범위

- 검색 로직, API 파라미터, 칩 제거 동작은 바꾸지 않는다.
- 이번 슬라이스는 스타일과 텍스트 구조만 다룬다.
- 모바일 전용 상단 고정 필터 바나 별도 요약 바는 넣지 않는다.

## 테스트

- 기존 칩 제거 테스트를 유지한다.
- 칩 텍스트가 `그룹 라벨: 값` 구조를 포함하는지 확인한다.
- 태그 칩이 개별적으로 표시되고 제거 가능한지 확인한다.
- 모바일 전용 시각 검증은 자동화하지 않고, 반응형 CSS 변경만 테스트 범위에 포함한다.
