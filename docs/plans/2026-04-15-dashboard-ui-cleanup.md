# 대시보드 UI 정리 구현 계획

1. 설계 문서 추가
- UI 정리 목표와 레이아웃 범위를 문서화한다.

2. 웹 테스트 추가
- 새 대시보드 구조를 검증하는 테스트를 먼저 추가한다.
- 기존 인증 대시보드 테스트를 새 레이아웃 기준으로 보강한다.

3. 공통 스타일 파일 추가
- `apps/web/src/App.css`를 추가한다.
- 카드, 그리드, 칩, 액션 그룹, 반응형 규칙을 정의한다.

4. `App.tsx` 레이아웃 정리
- 헤더/사이드바/메인 패널 구조를 추가한다.
- 검색 패널, 추천, 상세, 목록 영역에 구조용 클래스를 붙인다.

5. 폴더/태그/북마크 카드 정리
- 폴더 트리 행, 추천 항목, 북마크 항목의 내부 구조를 분리한다.
- 기존 버튼/레이블은 유지한다.

6. 검증
- `npm run test:web`
- `npm run test:api`
- `npm run build:web`

7. 커밋
- 문서 커밋
- 기능 커밋
