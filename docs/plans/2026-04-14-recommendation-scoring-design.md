# 추천 점수 고도화 설계

## 목표

기존 `즐겨찾기 추천`, `최근 열람`, `자주 연 링크` 3개 섹션은 유지하면서, 추천 순서가 단순 정렬이 아니라 실제 사용 패턴과 최근 문맥을 더 반영하도록 개선한다.

## 범위

- 북마크 열람 활동에서 `열람 수`와 `마지막 열람 시각`을 함께 집계
- 가장 최근에 연 북마크의 폴더/태그를 현재 문맥으로 사용
- 섹션별 정렬 점수에 다음 요소 반영
  - 즐겨찾기 여부
  - 누적 열람 수
  - 최근 열람 시각
  - 최근 문맥과의 폴더/태그 일치
- 응답 스키마와 대시보드 섹션 구조는 유지

## 접근 방식

- 활동 저장소에 `listOpenStats()`를 추가해 `bookmarkId`, `openCount`, `lastOpenedAt`를 한 번에 가져온다.
- 추천 라우트는 전체 북마크와 활동 통계를 합쳐 섹션별 점수를 계산한다.
- 가장 최근에 연 북마크와 같은 폴더면 큰 가산점, 태그가 겹치면 중간 가산점을 준다.
- 열람 이력이 없는 북마크는 `updatedAt` 기준 fallback 정렬을 유지한다.

## 섹션별 정렬 규칙

- `즐겨찾기 추천`
  - 즐겨찾기 북마크만 대상
  - `열람 수 + 최근성 + 문맥 점수`로 내부 정렬
- `최근 열람`
  - 마지막 열람 시각 우선
  - 동점이면 문맥 점수, 즐겨찾기, 수정 시각 순으로 정렬
- `자주 연 링크`
  - 열람 수 우선
  - 동점이면 문맥 점수, 최근성, 즐겨찾기 순으로 정렬

## 비범위

- 새 추천 섹션 추가
- 머신러닝/LLM 추천
- 사용자별 추천 규칙 설정 UI

## 검증 포인트

- 최근에 연 북마크와 같은 폴더/태그를 가진 링크가 더 위로 올라온다.
- 즐겨찾기 섹션 안에서도 실제 자주 쓰는 항목이 먼저 나온다.
- 활동 로그가 없는 북마크도 fallback 정렬로 추천 결과에 남는다.
