# 전체 UI 리디자인 설계

작성일: 2026-04-15

## 목표

- 현재 기능 구조를 유지한 채, 화면 전체를 더 차분하고 의도적인 개인 아카이브 작업 공간처럼 보이게 만든다.
- 데스크톱과 모바일 모두에서 정보 우선순위가 더 명확하게 읽히도록 시각 계층을 다시 설계한다.
- 최근에 만든 모바일 검색 패널, 모바일 작업 패널 탭, 압축형 카드 구조는 유지하면서 전체 스타일 시스템을 정리한다.

## 시각 방향

### 추천안: 조용한 운영형 앱

- 밝은 아이보리 계열 배경과 잉크색 텍스트를 중심으로 간다.
- 강조색은 한 가지 주황 계열로 제한한다.
- 화면은 “대시보드 카드 모음”보다 “정리된 개인 작업 공간”처럼 보여야 한다.
- 타이포 계층을 더 강하게 만들고, 불필요한 카드 느낌은 줄인다.

### 비교한 대안

1. 에디토리얼 워크벤치
- 아카이브 감성은 강하지만 현재 기능 밀도와 맞물리면 너무 장식적으로 흐를 수 있다.

2. 조용한 운영형 앱
- 정보 밀도, 차분한 작업성, 현재 레이아웃과의 연속성이 가장 좋다.
- 이번 리디자인 추천안이다.

3. 대비 강한 스튜디오형
- 시각 임팩트는 크지만 북마크 관리 앱의 장기 사용성보다 전시성에 가까워질 위험이 있다.

## 레이아웃 재구성

### 헤더

- 헤더는 더 얇고 넓게 정리한다.
- 서비스 이름과 짧은 설명, 계정 카드만 남기고 소음을 줄인다.
- 현재의 히어로 구조는 유지하되, 포스터형보다 작업 도구형 인상으로 조정한다.

### 메인 구조

- 데스크톱은 `왼쪽 작업 패널 / 오른쪽 작업 결과` 2열을 유지한다.
- 오른쪽은 `검색 -> 추천 -> 상세 -> 목록` 흐름이 더 분명하게 보이도록 위계와 간격을 다시 잡는다.
- 왼쪽 사이드바는 세 개의 독립 카드보다 하나의 작업 스택처럼 읽히게 만든다.

### 모바일 구조

- 모바일 검색 패널 토글 구조는 유지한다.
- 모바일 작업 패널 탭 구조는 유지한다.
- 모바일 북마크 압축 카드 구조도 유지한다.
- 이번 리디자인은 모바일 구조를 갈아엎지 않고, 현재 구조를 더 자연스럽고 일관되게 보이게 하는 데 집중한다.

## 컴포넌트별 리디자인 범위

### 검색 패널

- 검색 입력, 정렬, 액션 버튼의 우선순위를 더 강하게 만든다.
- 고급 필터 그룹은 지금보다 덜 카드형으로, 같은 작업 문맥 안의 하위 블록처럼 보이게 정리한다.
- 활성 칩은 “현재 작업 조건”으로 읽히게 라벨 위계를 더 선명하게 한다.

### 추천 영역

- 추천 3개 섹션은 유지하되, 헤더와 아이템의 시각 무게를 줄여 빠른 진입점처럼 보이게 만든다.
- 추천 이유, 폴더 정보, 열기 버튼은 유지하되 배치와 톤을 더 정리한다.

### 상세 패널

- 상세 패널은 가장 읽기 좋은 영역으로 승격한다.
- 제목, URL, 메타, 본문 블록, 액션 순서를 더 차분하게 정리하고 여백을 넉넉히 준다.

### 북마크 목록 카드

- 모바일 압축형 방향은 유지한다.
- 데스크톱 목록 카드는 제목과 요약 중심으로 다시 정돈하고, 배지는 스캔용 핵심만 앞에 남긴다.
- 메타와 액션이 같은 시각 무게로 경쟁하지 않게 조절한다.

### 작업 패널

- 북마크 저장, 폴더 관리, 태그 관리 폼은 같은 스타일 시스템으로 통일한다.
- 라벨, 필드, 보조 문구, 버튼 간격을 다시 맞춘다.
- 데스크톱에서는 작업 스택으로, 모바일에서는 탭 전환형 작업 공간으로 같은 정체성을 갖게 한다.

## 모션과 반응형

### 모션

- 과한 애니메이션은 넣지 않는다.
- 첫 진입, 카드 hover, 패널 전환에서 짧고 미묘한 움직임만 사용한다.
- 분위기를 정리하는 수준의 존재감만 허용한다.

### 반응형

- 모바일 검색 패널 토글 유지
- 모바일 작업 패널 탭 유지
- 모바일 추천/상세/북마크 카드 최적화 유지
- 반응형 구조를 새로 바꾸기보다 현재 구조의 시각 계층과 간격을 정교하게 맞춘다.

## 제외 범위

- 새 API 추가 없음
- 검색/추천 로직 변경 없음
- 저장/수정/드래그 기능 로직 변경 없음
- 디자인 시스템 분리 작업 없음

## 테스트 전략

### Web

- 기존 대시보드 구조 테스트는 유지한다.
- 모바일 검색 패널, 모바일 작업 패널 탭, 카드 압축 테스트가 계속 통과하는지 본다.
- 이번 슬라이스에서 기능 테스트를 새로 크게 늘리기보다, 기존 테스트 유지와 빌드 통과를 핵심 검증으로 둔다.

### 시각 검증

- 구현 후 로컬 실행으로 데스크톱/모바일에서 직접 시각 회귀를 확인한다.
- 특히 아래를 중점 확인한다.
  - 헤더와 계정 카드 위계
  - 사이드바 작업 스택의 일관성
  - 검색 패널의 첫 인상
  - 추천/상세/목록의 중요도 분리
  - 모바일 탭형 작업 패널과 압축 카드의 가독성
