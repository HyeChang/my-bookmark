# 모바일 검색 패널 사용성 보강 설계

## 목표

작은 화면에서 검색 패널이 공간을 과도하게 차지하지 않도록 정리하고, 검색 실행 흐름이 더 명확하게 보이게 만든다.

## 접근

### 1. 모바일 기본 상태

- 모바일에서는 검색 패널을 `접힌 상태`로 시작한다.
- 사용자는 `검색/필터 열기` 버튼으로 패널을 펼칠 수 있다.
- 데스크톱과 태블릿에 가까운 넓은 화면에서는 지금처럼 펼쳐진 구조를 유지한다.

### 2. 모바일 패널 구조

- 펼쳐진 상태 순서는 `기본 검색 -> 고급 필터 -> 활성 칩 -> 액션 버튼`으로 유지한다.
- `검색 실행`은 전체 폭 주 버튼으로 배치하고, `검색 초기화`는 그 아래 보조 버튼으로 분리한다.
- 활성 필터 칩은 세로 카드형 흐름에 맞게 폭을 충분히 확보한다.

### 3. 라벨과 상호작용

- 모바일 전용 토글은 `검색/필터 열기`, `검색/필터 닫기` 라벨을 쓴다.
- 데스크톱의 `고급 필터 열기/접기`와는 별개로, 모바일에서는 패널 전체를 여닫는 개념으로 본다.
- 패널이 접혀 있어도 활성 필터 개수는 헤더 근처에서 바로 알 수 있어야 한다.

### 4. 범위

- 검색 API, 필터 로직, 고급 필터 내용은 바꾸지 않는다.
- 이번 슬라이스는 모바일 전용 상태와 레이아웃만 다룬다.
- 추천/상세/목록 카드의 모바일 최적화는 다음 슬라이스로 넘긴다.

## 테스트

- 모바일 폭 환경에서 검색 패널이 기본 접힘 상태인지 확인
- 모바일 토글을 눌렀을 때 검색 필드와 고급 필터 버튼이 보이는지 확인
- 데스크톱 폭 환경에서는 기존처럼 바로 보이는지 유지
