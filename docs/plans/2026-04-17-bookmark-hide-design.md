# 북마크 숨김 설계

## 목표

- 폴더 숨김과 별도로 북마크 단위 숨김 기능을 추가한다.
- 숨김 북마크는 기본적으로 목록, 검색, 추천, 상세 진입 후보에서 보이지 않게 한다.
- 사용자가 별도의 좌물쇠 토글로 숨김 북마크만 독립적으로 표시하거나 숨길 수 있게 한다.

## 범위

- 북마크 모델과 API에 `isHidden` 정식 필드 추가
- 북마크 생성/수정 UI에 `숨김 북마크` 체크 추가
- 저장된 북마크 섹션 헤더에 `숨김 북마크 보기/숨기기` 좌물쇠 토글 추가
- 북마크 목록, 검색 결과, 추천, 상세 선택 가능 상태에 숨김 북마크 필터 적용
- 기존 폴더 숨김 토글은 그대로 유지하고 북마크 숨김과 분리

## 비범위

- 폴더 숨김 규칙 변경
- 숨김 북마크 전용 별도 페이지
- 확장 프로그램 전용 숨김 UI
- 숨김 북마크 암호화나 권한 단계 추가

## 접근 방식

### 추천안: 폴더 숨김과 동일한 패턴을 북마크에 독립 적용

- `bookmarks` 테이블에 `is_hidden` 컬럼을 추가한다.
- 공유 타입, API 요청/응답, 저장소 레이어 모두 `isHidden`을 정식 필드로 통일한다.
- 웹에서는 `showHiddenBookmarks` 로컬 상태를 따로 두고, 기존 `showHiddenFolders`와 완전히 분리한다.
- 대시보드에서 북마크 관련 데이터 소스만 `isHidden` 기준으로 필터링한다.
- 저장/수정 폼에서는 체크박스로 숨김 상태를 직접 바꿀 수 있게 한다.

장점:

- 기존 폴더 숨김 구현과 사고방식이 같아서 유지보수가 쉽다.
- 사용자 입장에서 폴더와 북마크 숨김을 명확히 분리할 수 있다.
- 검색, 추천, 상세 흐름까지 같은 기준으로 제어할 수 있다.

단점:

- 북마크 관련 모든 조회 경로를 한 번씩 점검해야 한다.
- 상세 패널에 이미 선택된 숨김 북마크가 있는 경우 정리 로직이 추가로 필요하다.

### 대안: 숨김 북마크를 검색/추천에서만 제외

- 구현은 조금 단순하지만, 목록과 상세 선택 상태가 서로 달라질 수 있다.
- 사용자 기대와 어긋나서 채택하지 않는다.

## 데이터 설계

### 스키마

- `bookmarks.is_hidden INTEGER NOT NULL DEFAULT 0`

### 공유 타입

- `Bookmark`
- `CreateBookmarkRequest`
- `UpdateBookmarkRequest`

위 세 타입에 `isHidden?: boolean`을 추가한다.

### 저장소

- 북마크 row 매핑에 `is_hidden`을 포함한다.
- `create`, `update`, `getByUserAndId`, `listByUser`, `searchByUser`의 결과에 숨김 상태를 유지한다.
- 숨김 필터는 저장소 내부 공통 필터로 둘지, 웹에서 처리할지는 단순성을 위해 웹에서 먼저 처리한다.

## UI 동작

### 북마크 생성/수정

- 북마크 작성 모달과 수정 흐름에 `숨김 북마크` 체크를 추가한다.
- 저장 시 `isHidden: true`면 숨김 북마크로 저장된다.
- 수정 시 숨김 상태를 다시 바꿀 수 있다.

### 저장된 북마크 섹션

- 헤더 액션에 `숨김 북마크 보기` 또는 `숨김 북마크 숨기기` 좌물쇠 버튼을 둔다.
- 토글이 꺼져 있으면 숨김 북마크는 목록에서 보이지 않는다.
- 토글이 켜져 있으면 숨김 북마크도 목록에 나타난다.

### 검색/추천/상세

- 숨김 북마크 토글이 꺼져 있으면 검색 결과와 추천에도 숨김 북마크를 포함하지 않는다.
- 이미 선택된 상세 북마크가 숨김이고 토글이 꺼지면 상세 패널은 선택 해제되거나 placeholder 상태로 돌아간다.
- 폴더 숨김 토글과 북마크 숨김 토글은 서로 영향을 주지 않는다.

## 상태 규칙

- `showHiddenFolders`: 폴더만 제어
- `showHiddenBookmarks`: 북마크만 제어

우선순위:

- 숨김 폴더에 속한 북마크는 폴더 숨김 토글이 꺼져 있으면 계속 보이지 않는다.
- 북마크 숨김 토글을 켜도 숨김 폴더 규칙까지 우회하지는 않는다.
- 즉 가시성은 `폴더 숨김`과 `북마크 숨김` 두 조건을 모두 만족해야 한다.

## 테스트 포인트

- 숨김 북마크 생성
- 숨김 북마크 수정
- 숨김 북마크 토글 전환에 따른 목록 표시 변화
- 검색 결과에서 숨김 북마크 제외/포함
- 추천에서 숨김 북마크 제외/포함
- 상세 패널이 숨김 토글 상태에 맞춰 정리되는지 확인
- 폴더 숨김과 북마크 숨김이 독립적으로 동작하는지 확인
