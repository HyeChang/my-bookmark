# 모바일 추천/상세 패널 정리 설계

## 목표

작은 화면에서 추천 링크와 북마크 상세 패널이 더 읽기 쉽고 누르기 쉬운 흐름을 갖도록 정리한다. 기능은 유지하고, 모바일 레이아웃과 액션 우선순위를 다듬는 데 집중한다.

## 접근

### 1. 추천 섹션

- 추천 3개 섹션은 현재처럼 세로로 이어지되, 각 추천 항목 내부를 `정보 블록`과 `행동 버튼`으로 명확히 분리한다.
- 모바일에서는 `열기` 버튼을 항목 전체 폭으로 늘려 터치 오차를 줄인다.
- 추천 항목 텍스트와 버튼 사이 간격을 늘려 카드 밀집감을 낮춘다.

### 2. 상세 패널

- 상세 패널 상단 정보는 유지하되, 액션 버튼은 모바일에서 세로 스택으로 정리한다.
- 버튼 우선순위는 `열기`, `수정 시작`, `자동 추출 다시 시도`, `사용자 입력 초기화`, `닫기`, `삭제` 순으로 둔다.
- 삭제는 마지막에 두고 시각적으로도 분리해서 실수 클릭 가능성을 낮춘다.

### 3. 상세 정보 블록과 이미지

- `사용자 입력값`, `자동 추출값`, 이미지 영역 간 세로 간격을 더 넓힌다.
- 모바일에서 업로드 이미지 그리드는 1열 고정으로 두고, 이미지 자체는 카드 폭에 맞춰 안정적으로 보이게 만든다.

### 4. 범위

- 검색 패널이나 북마크 카드 목록은 이번 슬라이스에서 건드리지 않는다.
- 추천 점수, 상세 데이터, API, 동작 로직은 유지한다.
- 이번 슬라이스는 모바일 레이아웃, 버튼 배치, 정보 간격만 다룬다.

## 테스트

- 상세 패널 액션 버튼 순서를 테스트로 고정한다.
- 기존 추천/상세 동작 테스트는 유지한다.
- 모바일 전용 CSS 자체는 자동 검증하지 않고, DOM 구조와 버튼 순서 중심으로 검증한다.
