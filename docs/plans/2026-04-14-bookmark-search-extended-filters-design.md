# 북마크 확장 검색 필터 설계

## 목표

기존 기본 검색 필터(`즐겨찾기만`, `폴더`, `태그`) 위에 아래 3개를 추가한다.

- `북마크 색상` 정확 일치 필터
- `URL 색상` 정확 일치 필터
- `요약 있음/없음` 필터

검색어와 검색 모드가 있든 없든 동일하게 조합 가능해야 한다.

## 접근 방식

### 1. API 필터 확장

`GET /api/bookmarks`에 아래 쿼리 파라미터를 추가한다.

- `bookmarkColor`
- `urlColor`
- `summaryState=all|with|without`

서버는 기존 검색 흐름을 유지하되, 목록/검색 모두 같은 필터 헬퍼를 통해 적용한다.

### 2. UI 필터 확장

기존 검색 폼 아래에 다음 입력을 추가한다.

- `북마크 색상 필터`
- `URL 색상 필터`
- `요약 필터`

색상은 현재 저장 구조가 자유 입력 문자열이므로 1차에서는 텍스트 입력으로 둔다.
요약은 선택형으로 둔다.

## 필터 규칙

### 색상

- 비교 전 앞뒤 공백 제거
- 대소문자 차이는 무시
- 완전 일치만 허용

### 요약

- `with`: `displaySummary.trim().length > 0`
- `without`: `displaySummary.trim().length === 0`
- `all`: 필터 미적용

## 상태 처리

- `검색 초기화`는 기존 기본 필터와 확장 필터를 모두 비운다.
- 활성 필터 요약 문구에도 색상/요약 필터를 반영한다.
- 기본 필터 삭제 시 정리 로직은 유지하고, 확장 필터는 별도 참조 정리 대상이 없다.

## 테스트 전략

### API

- 색상 + 요약 필터만으로 목록 필터링
- 검색어 + 요약 없음 필터 조합

### Web

- 색상/요약 필터를 입력한 뒤 검색 실행 시 쿼리 문자열 확인
- 검색 초기화 시 모든 확장 필터 초기화 확인
