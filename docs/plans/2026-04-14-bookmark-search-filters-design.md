# 북마크 검색 기본 필터 설계

## 목표

북마크 검색에서 검색어와 검색 모드 외에 기본 필터를 함께 적용할 수 있도록 한다. 1차 필터 범위는 `즐겨찾기만`, `폴더`, `태그`로 제한한다.

## 범위

- API `GET /api/bookmarks`에 기본 필터 파라미터 추가
- 검색어 없이도 필터만으로 목록 조회 가능
- 검색어가 있으면 검색 모드와 필터를 함께 적용
- 웹 북마크 목록 상단에 기본 필터 UI 추가
- 검색 초기화 시 필터 상태도 함께 초기화

## 접근 방식

- API는 `favorite=1`, `folderId`, `tagId` 쿼리 파라미터를 받는다.
- 저장소는 전체 목록과 검색 결과 모두 동일한 필터 함수를 통과하도록 정리한다.
- UI는 기존 검색 폼에 체크박스 1개와 셀렉트 2개를 추가한다.
- 1차에서는 태그 단일 선택만 지원하고, 다중 태그 조합은 다음 단계로 미룬다.

## 동작 규칙

- `즐겨찾기만`: `isFavorite = true`인 북마크만 노출
- `폴더`: 선택한 `folderId`와 일치하는 북마크만 노출
- `태그`: 선택한 `tagId`를 포함하는 북마크만 노출
- 검색어와 필터를 같이 주면 교집합 결과만 노출

## 비범위

- 다중 태그 필터
- 색상/요약/최근 추가/최근 열람 필터
- 저장된 필터 프리셋

## 검증 포인트

- 검색어 없이 즐겨찾기 필터만으로 목록을 좁힐 수 있다.
- 폴더/태그 필터가 검색 결과에도 같이 적용된다.
- 검색 초기화 시 검색어, 모드, 필터가 모두 기본값으로 돌아간다.
