# 검색 패널 UX 정리 설계

## 목표

검색 패널에서 현재 상태와 조작 단계를 더 빠르게 이해할 수 있게 만든다.

- 기본 검색과 고급 필터의 역할을 시각적으로 분리
- 고급 필터 내부를 `기간`, `분류`, `상태` 그룹으로 재구성
- 적용된 검색 조건은 칩만 나열하지 않고 `선택된 필터 n개` 요약으로 보강
- 모바일에서도 필터 구조가 무너지지 않게 정리

## 접근 방식

### 1. 기본 검색 영역

- 검색어, 검색 모드, 정렬, 고급 필터 토글을 한 묶음으로 유지
- 패널 상단에 짧은 안내 문구를 추가해 “무엇을 여기서 조합하는지”를 설명

### 2. 고급 필터 그룹화

고급 필터를 한 덩어리로 두지 않고 다음 그룹으로 나눈다.

- `기간`
  - 최근 추가
  - 최근 열람
- `분류`
  - 즐겨찾기만
  - 필터 폴더
  - 하위 폴더 포함
  - 태그 조건
  - 필터 태그
- `상태`
  - 북마크 색상
  - URL 색상
  - 요약 필터

### 3. 상태 요약

- 활성 필터 카드 상단에 `선택된 필터 n개`를 표시
- 칩 제거 동작은 그대로 유지
- 필터가 없는 경우 요약 카드는 숨김 유지

### 4. 버튼/모바일 UX

- 고급 필터 버튼은 열림 상태에 따라 `고급 필터 열기` / `고급 필터 접기`로 바뀐다.
- 모바일에서는 검색 액션 버튼을 전체 폭에 가깝게 보이도록 정리한다.

## 제외 범위

- 검색 기능 로직 변경
- 새 필터 추가
- 검색 결과 정렬 방식 변경

## 테스트 전략

### Web

- 고급 필터 버튼 라벨이 열림/닫힘에 따라 바뀌는지 확인
- 고급 필터를 열면 `기간`, `분류`, `상태` 그룹 제목이 보이는지 확인
- 검색 실행 후 `선택된 필터 n개`가 보이는지 확인
