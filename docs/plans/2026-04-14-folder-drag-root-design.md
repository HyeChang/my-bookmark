# Folder Drag Root Design

## Goal

하위 폴더를 드래그해서 최상위 폴더 영역에 드롭하면 `parentFolderId=null`로 이동시키고, 폴더 트리와 모든 폴더 선택 순서가 바로 반영되게 만든다.

## Scope

- 폴더 관리 영역 상단에 `최상위로 이동` drop 영역 추가
- 드래그 중인 폴더를 이 영역에 드롭하면 최상위로 이동
- 이동된 폴더는 최상위 폴더 목록의 마지막 순서로 붙음
- 계층 옵션과 트리 UI는 서버 응답 폴더 목록으로 즉시 갱신

## Non-Goals

- 임의 루트 위치 삽입
- 여러 폴더 동시 이동
- 드롭 미리보기 스타일 개선

## API Design

- 기존 `POST /api/folders/:folderId/move` 재사용
- 요청 본문:
  - `parentFolderId: null`
- 서버 동작:
  - 이미 최상위인 폴더를 다시 루트로 이동하면 무시
  - 이전 부모/최상위 형제 `sortOrder`는 저장소가 정규화

## UI Design

- `폴더 관리` 폼 아래, 폴더 목록 위에 `최상위로 이동` drop 영역 추가
- drag handle은 기존 `드래그 정렬` 버튼을 그대로 사용
- 현재 최상위 폴더는 이 영역에 드롭해도 아무 일도 하지 않음

## Testing

- API:
  - 자식 폴더를 루트로 이동시키는 테스트 추가
- Web:
  - 루트 drop 후 하위 폴더가 최상위 폴더로 보이는지
  - 저장 폼/검색 폼의 폴더 선택 순서가 새 구조를 반영하는지
