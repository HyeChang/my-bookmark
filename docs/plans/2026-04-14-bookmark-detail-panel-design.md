# 북마크 상세 패널 설계

## 목표

저장된 북마크 목록에서 `상세 보기`를 누르면 같은 화면 안에서 선택한 북마크의 상세 정보를 확인할 수 있도록 한다.

## 범위

- 목록 항목에 `상세 보기` 버튼 추가
- 인페이지 상세 패널 추가
- 상세 패널에서 다음 정보 표시
  - 표시 제목
  - 원본 URL
  - 폴더명
  - 태그명
  - 사용자 입력 제목/내용/요약
  - 자동 추출 제목/내용/요약
  - 업로드 이미지
- 상세 패널에서 다음 동작 제공
  - `열기`
  - `수정 시작`
  - `닫기`

## 접근 방식

- 기존 `GET /api/bookmarks/:id` API를 재사용해 상세 데이터를 가져온다.
- 이미지 목록은 기존 `GET /api/bookmarks/:bookmarkId/assets`를 재사용한다.
- 화면 구조는 현재 단일 `App.tsx` 안에서 상태 기반으로 처리한다.
- 편집 폼은 유지하고, 상세 패널에서 `수정 시작`을 누르면 기존 편집 흐름으로 넘긴다.

## 비범위

- 별도 URL 라우트 페이지 분리
- 북마크 삭제
- 이미지 대표 지정
- 댓글/본문 추출 품질 개선

## 검증 포인트

- `상세 보기` 클릭 시 상세 패널이 열린다.
- 상세 패널에 사용자 입력값과 자동 추출값이 구분되어 표시된다.
- 폴더명과 태그명이 표시된다.
- 업로드 이미지가 표시된다.
- `수정 시작` 클릭 시 기존 편집 모드로 전환된다.
