# 대시보드 카드 UX 정리 설계

## 목표

추천 카드와 북마크 카드의 정보 밀도와 스캔 속도를 개선한다.

- 추천 카드는 왜 추천됐는지 바로 보이게 한다.
- 북마크 카드는 현재 상태를 배지 중심으로 빠르게 읽을 수 있게 한다.
- 카드 구조는 이미지 유무에 흔들리지 않게 유지한다.

## 시각 방향

### Visual Thesis

운영 도구답게 담백하지만, 카드 하나만 봐도 상태와 다음 행동이 한눈에 들어오는 구조로 정리한다.

### Content Plan

- 추천 카드: 제목, 추천 이유, 보조 메타, 열기 액션
- 북마크 카드: 제목, URL, 상태 배지, 요약, 썸네일/이미지 메타, 액션

### Interaction Thesis

- 배지는 클릭 가능한 필터가 아니라 읽기용 상태 요약으로 둔다.
- 주요 액션은 `열기`, 보조 액션은 `상세 보기/수정/삭제` 순서로 유지한다.
- 카드 자체는 과도한 모션 없이 hover 시 미세한 상승과 윤곽 강조만 준다.

## 접근 방식

### 1. 추천 카드 정리

각 추천 열의 항목에 아래 정보를 추가한다.

- `추천 이유` 배지
  - 즐겨찾기 추천: `즐겨찾기 기반`
  - 최근 열람: `최근 열람 기반`
  - 자주 연 링크: `반복 열람 기반`
- 폴더명 보조 배지
- 요약이 없을 때는 `요약 없음` 보조 텍스트

### 2. 북마크 카드 상태 배지

북마크 카드에 아래 배지를 추가한다.

- `즐겨찾기`
- 폴더명
- 요약 상태
  - `수동 요약`
  - `자동 요약`
  - `요약 없음`
- `태그 n개`
- 이미지가 있으면 `이미지 n장`

### 3. 색상 메타 표현

북마크 색상과 URL 색상이 있으면 작은 색상칩을 추가한다.

- 텍스트와 스와치를 함께 보여준다.
- 예: `북마크 색상 #f59e0b`, `URL 색상 #0f172a`

이미 색상 필터 기능이 있으므로, 현재 저장값을 카드에서 읽을 수 있게 만드는 의미가 있다.

### 4. 카드 구조 원칙

- 제목과 URL은 상단 고정
- 배지 줄은 요약보다 먼저
- 액션 줄은 카드 맨 아래 고정
- 이미지가 있으면 카드 중간에 소형 썸네일 영역으로 노출

## 제외 범위

- 대표 이미지 지정
- 추천 점수 로직 변경
- 카드 클릭 시 전체 열기
- 상세 패널 정보 구조 변경

## 테스트 전략

### Web

- 추천 카드에 추천 이유 텍스트가 보이는지 확인
- 북마크 카드에 `수동/자동/없음` 요약 상태 배지가 보이는지 확인
- 태그 수, 이미지 수, 색상 메타가 카드에 보이는지 확인

API 변경은 없으므로 기존 API 테스트는 유지한다.
