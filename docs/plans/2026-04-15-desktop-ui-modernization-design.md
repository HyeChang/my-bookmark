# 데스크톱 UI 현대화 설계

작성일: 2026-04-15

## 목표

- 데스크톱 기준으로 스크롤 길이를 줄이고, 겹치거나 깨지는 UI를 정리한다.
- 북마크 앱처럼 `탐색`, `목록`, `상세`의 중심 흐름이 잘 보이게 재배치한다.
- 상시 노출되는 조작 수를 줄이고, 드롭다운/모달로 이동시켜 더 컴팩트하고 현대적인 작업 화면으로 바꾼다.

## 참고 방향

- 정보 구조: `Raindrop.io`
- 상세/읽기 흐름: `GoodLinks`
- 시각 톤: 현재 색조를 유지하되 더 차분하고 정돈된 운영형 UI

즉, 많은 카드와 많은 버튼을 동시에 보여주는 방식이 아니라, 조용한 작업 도구처럼 `필요한 정보만 먼저 보이고`, `덜 자주 쓰는 조작은 숨기는` 구조로 간다.

## 구조 개편

화면은 `좌측 탐색`, `중앙 목록`, `우측 상세`의 3영역으로 재정리한다.

- 좌측
  - 폴더 트리
  - 최소 탐색 정보
  - `새 북마크`, `새 폴더`, `태그 관리` 진입 버튼
- 중앙
  - 검색 바
  - 필터 요약
  - 추천 영역
  - 저장된 북마크 목록
- 우측
  - 선택된 북마크 상세 보기
  - 상세 액션

현재 좌측에 길게 노출된 `북마크 저장`, `폴더 관리`, `태그 관리`의 상시 폼 구조는 데스크톱에서도 스크롤을 늘리고 작업 중심을 흐린다. 따라서 좌측은 `탐색과 진입`만 담당하고, 생성/수정은 별도 오버레이 흐름으로 바꾼다.

## 드롭다운 / 모달 전략

### 상시 노출

- 검색 입력
- 폴더 트리
- 북마크 목록
- 북마크 상세 패널

### 드롭다운 / 팝오버

- 검색 고급 필터
- 정렬
- 태그 필터
- 색상 필터
- 카드별 빠른 액션
- 폴더 행의 보조 액션

### 모달 / 슬라이드오버

- 새 북마크 생성
- 북마크 수정
- 폴더 생성 / 수정
- 태그 관리

핵심 원칙은 `자주 보는 것만 화면에 남기고`, `조작은 눌렀을 때만 펼친다`는 것이다.

## 폴더 UI 정리

현재 폴더 행은 버튼이 많아 줄바꿈과 겹침이 쉽게 발생한다. 이를 다음처럼 단순화한다.

- 기본 행 노출
  - 폴더 이름
  - 부모/하위 여부 보조 정보
  - 필요 최소 배지
  - `···` 액션 메뉴
- 메뉴 안으로 이동
  - 수정
  - 삭제
  - 하위로 이동 관련 보조 액션
- 드래그 정렬은 유지하되, 시각적으로는 더 얇고 조용한 핸들만 둔다.

즉, 정렬 기능은 남기되 상시 큰 버튼 묶음은 제거한다.

## 검색 패널 압축

검색은 상단 바 중심으로 정리한다.

- 상단 1행
  - 검색어
  - 검색 모드
  - 정렬
  - `필터` 버튼
- 별도 팝오버
  - 기간
  - 즐겨찾기
  - 폴더
  - 태그
  - 색상
  - 요약 조건
- 적용된 조건은 칩으로 유지하되, 더 단정한 밀도와 구분으로 정리한다.

이 구조로 바꾸면 메인 화면에서 필터가 차지하는 세로 길이를 크게 줄일 수 있다.

## 시각 톤

### 버튼

- 큰 둥근 버튼 남발을 줄인다.
- 기본 버튼 높이와 패딩을 더 낮고 정돈되게 맞춘다.
- 파괴적 액션은 위험 톤을 유지하되 상시 강조를 줄인다.

### 카드 / 표면

- 카드 수를 줄인다.
- 카드 안의 또 다른 카드처럼 보이는 내부 박스는 최소화한다.
- 얇은 경계선, 낮은 그림자, 더 넓은 여백으로 정리한다.

### 텍스트

- 제목 대비를 높인다.
- 설명 문구는 짧게 유지한다.
- 보조 텍스트는 더 작은 크기와 옅은 색으로 정리한다.

### 색상

- 남색/주황/베이지의 강한 충돌을 줄인다.
- 포인트는 1개 계열 중심으로 유지하고, 나머지는 중성 톤으로 후퇴시킨다.

## 반응형 범위

- 이번 작업의 1차 목표는 `데스크톱 사용성 우선`이다.
- 모바일 구조는 현재 흐름을 유지하되, 데스크톱 개편으로 깨지는 부분이 없도록만 보정한다.
- 따라서 모바일 전체 구조 재설계는 이번 범위에 포함하지 않는다.

## 검증 범위

- 웹 테스트
  - 좌측 패널에 상시 긴 폼이 남지 않는지
  - 생성/수정 진입 버튼이 모달/오버레이를 여는지
  - 폴더 행이 메뉴 기반 구조로 바뀌는지
  - 검색 패널이 압축된 구조를 유지하는지
- 수동 확인
  - 데스크톱에서 세로 스크롤이 줄었는지
  - 폴더 행 버튼 겹침이 사라졌는지
  - 긴 텍스트와 버튼이 서로 밀어내지 않는지

## 구현 순서

1. 레이아웃 재배치
2. 생성/수정 흐름 모달화
3. 폴더 행 단순화
4. 검색 패널 압축
5. 시각 톤 정리
