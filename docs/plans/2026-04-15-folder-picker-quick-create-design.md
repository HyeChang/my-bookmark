# 폴더 선택형 입력 + 인라인 빠른 폴더 생성 설계

## 목표

폴더 관련 입력을 자유 텍스트에서 선택형 UI로 바꾸고, URL 등록 중에도 폴더를 바로 만들 수 있게 한다. 동시에 폴더 추가와 북마크 저장에서 보이는 `Failed to fetch` 문제를 원인 분리가 가능한 에러 처리 구조로 바꾼다.

## 범위

- 폴더 색상 입력 제거, 팔레트 선택으로 변경
- 폴더 아이콘 입력 제거, 고정 아이콘 선택으로 변경
- 북마크 저장 폼 안에 인라인 빠른 폴더 추가 영역 제공
- 빠른 폴더 추가에서 부모 폴더 선택 지원
- 폴더가 없을 때는 최상위 폴더로 생성
- 공용 fetch 에러 파서 추가
- 폴더 생성 / 북마크 저장 관련 테스트 보강

## 접근 방식

### 선택안

1. 최소 패치형
   - 폴더 관리 폼과 북마크 폼에 필요한 UI만 따로 추가
   - 빠르지만 입력 규칙이 두 군데로 갈라진다.

2. 공용 입력 모델 정리형
   - 폴더 색상 팔레트와 아이콘 프리셋을 상수화
   - 폴더 관리 폼과 인라인 빠른 폴더 추가가 같은 선택 UI를 재사용
   - 공용 fetch 에러 파서를 도입
   - 이번 변경 범위에 가장 적절하다.

3. 대형 폼 리팩터링형
   - 북마크/폴더/태그 폼 구조를 한 번에 재구성
   - 지금 요구에 비해 범위가 과하다.

### 결정

`공용 입력 모델 정리형`으로 간다.

## UI 설계

### 폴더 색상

- 텍스트 입력 제거
- 미리 정한 8개 안팎의 색상 프리셋을 버튼 그리드로 제공
- 선택된 색상은 활성 상태로 강조
- `선택 안 함` 옵션도 같이 제공

### 폴더 아이콘

- 텍스트 입력 제거
- 미리 정한 아이콘 ID를 선택 버튼으로 제공
- 1차 범위에서는 현재 데이터 모델의 문자열 값을 유지하고, UI만 선택형으로 제한
- `선택 안 함` 옵션 제공

### URL 등록 중 빠른 폴더 추가

- `저장 폴더` 선택 바로 아래에 `새 폴더 바로 추가` 영역을 둔다
- 기본 상태는 접힘
- 펼치면 아래 항목을 입력할 수 있다
  - 폴더 이름
  - 폴더 색상 선택
  - 폴더 아이콘 선택
  - 부모 폴더 선택
- 폴더가 없으면 부모 선택은 비활성화하고, 생성 시 자동으로 최상위 폴더가 된다
- 생성 성공 시
  - 폴더 목록 갱신
  - 새 폴더를 `저장 폴더`로 자동 선택
  - 빠른 폴더 추가 폼 초기화
  - 빠른 폴더 추가 영역 접기

## 데이터 / API

- API 스키마는 그대로 유지한다
  - `color`, `icon`, `parentFolderId`는 문자열 또는 null
- 서버는 별도 프리셋 검증을 추가하지 않는다
  - 1차는 UI에서만 선택 가능하게 제한
- 북마크 저장 중 폴더를 새로 만드는 동작은 별도 API 조합으로 처리한다
  - `POST /api/folders`
  - 성공 후 `POST /api/bookmarks`

## 에러 처리

### 현재 문제 해석

- 현재 web fetch helper는 HTTP 오류와 네트워크 예외를 구분하지 않는다
- 네트워크 예외가 나면 브라우저의 기본 메시지인 `Failed to fetch`가 그대로 노출된다
- 사용자가 본 증상은
  - 서버 미실행
  - 서버 런타임 예외
  - 브라우저 레벨 fetch 실패
  중 하나일 수 있으므로, 우선 메시지 계층을 분리한다

### 개선 방향

- `apps/web/src/lib/api.ts`에 공용 fetch helper 추가
- 동작 규칙:
  - JSON 에러 바디가 있으면 `error` 코드를 읽는다
  - 네트워크 예외면 한국어 안내 메시지로 바꾼다
  - 응답이 JSON이 아니면 기본 액션별 fallback 메시지를 사용한다
- 폴더/북마크/태그/추출 관련 helper가 이 공용 fetch helper를 사용하도록 바꾼다

### 1차 사용자 메시지 규칙

- 네트워크 실패:
  - `로컬 서버에 연결하지 못했습니다. 실행 중인지 확인해주세요.`
- 폴더 생성 실패:
  - 서버 error code가 있으면 코드별 메시지
  - 없으면 `폴더를 저장하지 못했습니다.`
- 북마크 저장 실패:
  - `invalid_url` 등은 구체 메시지
  - 없으면 `북마크를 저장하지 못했습니다.`

## 테스트 전략

### API

- 기존 폴더 생성 테스트에 부모 폴더 지정 유지 확인
- 북마크 생성 테스트는 기존 흐름 유지

### Web

- 폴더 관리 폼이 팔레트/아이콘 선택형으로 렌더링되는지 확인
- 북마크 저장 폼에서 빠른 폴더 추가로 폴더 생성 후 자동 선택되는지 확인
- 폴더가 없을 때 부모 선택이 비활성화되는지 확인
- 네트워크 오류가 `Failed to fetch` 대신 안내 메시지로 바뀌는지 확인

## 제외 범위

- 아이콘 검색 기능
- 사용자 임의 색상 입력
- 서버 측 프리셋 화이트리스트 검증
- 폴더 생성 모달
