# 모바일 작업 패널 헤더 요약 구현 계획

작성일: 2026-04-15

## 구현 순서

1. 모바일 패널 헤더 요약 텍스트를 검증하는 웹 테스트 추가
2. 실패 테스트 실행으로 현재 헤더 정보 부족 상태 확인
3. `App.tsx`에 패널별 요약 문자열 계산 로직 추가
4. 모바일 패널 토글 헤더에 요약 텍스트와 상태 배지 반영
5. `App.css`에 헤더 요약과 상태 배지 스타일 추가
6. 웹 테스트 재실행
7. 전체 검증(`test:api`, `test:web`, `build:web`)

## 수정 대상

- `apps/web/src/App.tsx`
- `apps/web/src/App.css`
- `apps/web/src/test/bookmark-dashboard.test.tsx`

## 상태 계산 기준

- 북마크 패널: `새 북마크`, `작성 중`, `수정 중`
- 폴더 패널: `폴더 N개`, `수정 중 · 폴더 N개`
- 태그 패널: `태그 N개`, `수정 중 · 태그 N개`

## 검증 포인트

- 모바일 기본 상태에서 헤더 요약이 보이는지
- 패널 전환 동작이 기존처럼 유지되는지
- 데스크톱 렌더링이 깨지지 않는지
